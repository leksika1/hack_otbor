# Пример разбора реальной сессии

Разбор обезличенного лога Claude Code, выданного организаторами (8,7 МБ, 1232 строки,
438 шагов, 18,5 часов с паузами, оценка стоимости ≈ $26.53). Ничего не подгонялось под
этот лог заранее: он содержит фоновые задачи, `/compact`, вложения и очередь команд.

```bash
python -m backend.cli session.jsonl --out-dir docs/example-report > docs/example-report/REPORT.txt
```

| Файл | Что это |
| --- | --- |
| [REPORT.txt](REPORT.txt) | Диагностика: находки по значимости со ссылками на шаги, причина, цена, что сделать |
| [NEXT_SESSION.md](NEXT_SESSION.md) | Чек-лист к следующей сессии, сгруппирован по типу правки |
| [CLAUDE.md.append.md](CLAUDE.md.append.md) | Блок для вставки в `CLAUDE.md`, у каждого правила - шаги, из которых оно выведено |
| [AGENTS.md](AGENTS.md) | Те же правила по темам |

Находки посчитаны кодом; LLM (`nvidia/nemotron-3-super-120b-a12b:free` через OpenRouter)
получила не лог, а по несколько шагов вокруг пяти самых значимых групп находок - из
1,17 млн токенов сессии в модель ушло несколько тысяч.
